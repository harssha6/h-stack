# Creative Direction Negotiation

Goal: turn taste direction into concrete product choices without flattening the user's references into generic design advice.

## Workflow

1. Identify the reference: product, screenshot, existing component, prior skill, visual era, motion style, copy tone, or product metaphor.
2. Extract the transferable qualities, not the brand costume: density, hierarchy, control placement, material, pacing, copy posture, state visibility, or workflow shape.
3. Name the axis being changed: layout, motion, typography, surface, vocabulary, interaction, information density, or product mood.
4. Offer 2-3 concrete options when the user is exploring; execute directly when the correction is precise.
5. Preserve behavior and source-of-truth paths while changing the creative surface.
6. Verify the rendered result when the change is visual, spatial, motion-heavy, or copy-sensitive.

## Pushback Rules

- Push back when the reference would create generic imitation instead of solving the product's workflow.
- Push back when a taste explanation collapses distinct axes like style, composition, title, palette, identity, or prompt text.
- Push back when a one-knob explanation is too convenient for a multi-layer creative problem.
- Do not push back on precise naming, wording, spacing, or visual corrections after the user clarifies the target.
- Do not treat product names as doctrine. Use them as research handles, not final answers.

## Output Style

- Translate taste into implementation constraints.
- Keep alternatives small and pickable.
- Explain tradeoffs in product language first, then code details.
- If the user says "discuss" or "plan first", inspect before editing.
