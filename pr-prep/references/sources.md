# Research sources

Inspected 2026-10-10. This skill is an original project-aware preparation workflow, not an installation of either upstream skill.

- [Sentry pr-writer](https://github.com/getsentry/skills/blob/main/skills/pr-writer/SKILL.md): useful model for a concise reviewer cover note and full-diff inspection. Its conventional-title and automatic creation steps are not adopted as universal rules; local project conventions and user authorization own those choices.
- [wk entaro sending-pull-request](https://github.com/wkentaro/agent-skills/blob/main/skills/engineering/sending-pull-request/SKILL.md): useful separation of copy-only work and publication. Default-branch reset, force push, and automatic readiness actions are not adopted.
- [GitHub CODEOWNERS](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/about-code-owners): base-branch authority, file precedence, last-match behavior, access requirements, and alternative owners.

The user-facing categorization, exact inclusions/exclusions, required-versus-recommended reviewer distinction, and evidence boundaries come from the requested workflow. Current project rules must always be rediscovered.
